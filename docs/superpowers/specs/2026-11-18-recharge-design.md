# USDT 充值功能

目标：完成参考图中的移动端充值页面，打通充值入口、收款信息、转账申报、记录和后台核实入账。

沿用 Vue 3/Vant、Element Plus、Go/Gin/GORM/MySQL。界面按参考图提供黑色背景、二维码卡片、地址复制、风险提示和底部紫色按钮。桌面继续使用现有 480px 手机容器。

方案：使用后台人工核实模式。链上自动到账需要尚不存在的节点/支付服务和签名回调，因此本次不接入。地址存入现有 settings 表，默认留空，不采用图片里的地址。二维码在浏览器本地生成，内容与显示/提交的地址完全一致。

用户点击完成转账后，填写原始 USDT 金额和 64 位交易哈希。后端校验最低 1 USDT，截断至两位小数并保留原始输入；保存用户、地址快照和全局唯一哈希，初始状态待核实。个人记录仅返回本用户数据。管理员核实交易的网络、币种、收款地址、金额及付款归属后确认或驳回；公开交易哈希不能单独证明付款归属，确认入账必须填写用户可见的核验说明。确认操作在同一事务内更新状态、钱包和流水，防止重复入账。

地址未配置、读取失败、二维码失败、提交失败都提供明确反馈与重试，不显示成功或虚构记录。若地址在页面打开后被修改，提交时要求刷新重新核对。

验收：两端构建、Go 全量测试、金额/地址/哈希校验、鉴权隔离、确认事务幂等与回滚，以及浏览器移动尺寸页面交互。
